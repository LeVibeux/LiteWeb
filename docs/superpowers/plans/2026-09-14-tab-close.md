# Tab Close (bouton × + `:tab close`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close a tab without the keyboard: a × button on each tab header and `:tab close [N]` in the command palette, both reusing the Ctrl+W path.

**Architecture:** Fix the `active`-index bug in `TabManager::close_tab`; extract a single UI helper `BrowserWindow::close_tab_at(state, index)` (close → recreate `about:blank` if empty → `render_tabs(state, true)`); wire Ctrl+W, `:tab close`, and the new × button through it. The tab header becomes a horizontal `GtkBox` (title `Label` + close `Button`).

**Tech Stack:** Rust, GTK3, WebKitGTK, existing LiteWeb command palette.

**Spec:** `docs/superpowers/specs/2026-09-14-tab-close-design.md`

## Global Constraints

- Reuse `BrowserWindow::close_current_tab` / new `close_tab_at` helper; when the last tab is closed, recreate `about:blank` then `render_tabs(state, true)` — no duplication of the last-tab logic.
- `TabManager::close_tab` must decrement `active` when closing an index `< active` (bug today: `[A,B,C]` active `B`, close `A` → active becomes `C`).
- `set_active` must never clear `Suspended` (existing test `set_active_does_not_clear_suspended_state` guards this — do not touch `set_active`).
- Closing a suspended tab must NOT call `wake()`: the tab is dropped, never restored.
- The × button callback captures `tab.id` (not the index) and resolves `index_of_id` at click time.
- `notebook_sync_depth` / `with_notebook_sync` stay in force around structural notebook rebuilds (`render_tabs(..., true)` already begins/ends sync — do not bypass it).
- Parsing: `:tab close` and `:t close` → `TabClose(None)`; `:tab close N` is 1-indexed → `TabClose(Some(n.saturating_sub(1)))`; any other trailing junk → `Unknown`.
- Ctrl+W behavior unchanged besides sharing `close_tab_at`.
- Graphical header: `GtkBox` containing the existing title `Label` (still stored in `tab.tab_label`) + a close `Button`; `update_tab_label` still only sets the `Label`.
- Out of scope: middle-click close, `:tc` alias, confirmation dialogs, close-all / close-others, any Ctrl+W change.

Note: the crate has only a `[[bin]]` target (`liteweb`), so unit tests run with plain `cargo test` (optionally filtered by module path).

```rust
pub fn close_tab(&mut self, index: usize) -> bool {
    if self.tabs.is_empty() {
        return false;
    }
    if index >= self.tabs.len() {
        return false;
    }
    self.tabs.remove(index);
    if self.tabs.is_empty() {
        self.active = 0;
        return true;
    }
    if index < self.active {
        self.active -= 1;
    }
    if self.active >= self.tabs.len() {
        self.active = self.tabs.len() - 1;
    }
    true
}
```

Do not change `set_active`.

- [ ] **Step 1: Extract the helper**

Replace the current `close_current_tab` in `src/ui/window.rs`:

```rust
fn close_tab_at(state: Rc<RefCell<AppState>>, index: usize) {
    if state.borrow_mut().tabs.close_tab(index) {
        if state.borrow().tabs.tabs().is_empty() {
            state.borrow_mut().tabs.create_tab("about:blank");
        }
        // Structural rebuild — render_tabs(…, true) holds notebook_sync_depth
        // for the whole rebuild, same path Ctrl+W already exercised.
        Self::render_tabs(state, true);
    }
}

fn close_current_tab(state: Rc<RefCell<AppState>>) {
    let idx = state.borrow().tabs.active_index();
    Self::close_tab_at(state, idx);
}
```

Keep those four lines, then add right after them:

```rust
let close_btn = Button::with_label("×");
close_btn.set_relief(gtk::ReliefStyle::None);
close_btn.set_focus_on_click(false);
close_btn.set_tooltip_text(Some("Fermer l'onglet"));
let close_tab_id = tab.id; // capture the stable id, never the index
let state_close = state_for_tabs.clone();
close_btn.connect_clicked(move |_| {
    let state = state_close.clone();
    // Defer: the structural rebuild destroys this very button; don't
    // tear the notebook down while its clicked signal is still emitting.
    glib::idle_add_local_once(move || {
        // Resolve the index at click time — earlier closes shift indices.
        let idx = state.borrow().tabs.index_of_id(close_tab_id);
        if let Some(idx) = idx {
            // No wake(): closing a suspended tab drops it, never restores it.
            Self::close_tab_at(state, idx);
        }
    });
});

let tab_header = GtkBox::new(Orientation::Horizontal, 2);
tab_header.pack_start(&label, false, false, 0);
tab_header.pack_start(&close_btn, false, false, 0);
```
